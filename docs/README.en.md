# Chrome Remote Desktop Image Paste

**Screenshot locally. Ctrl+V remotely.**

[Download for Windows](https://github.com/evan6007/chrome-remote-desktop-image-paste/releases/tag/v0.2.0-rc.1) · [Install guide](INSTALL.md) · [繁體中文](../README.md)

![Screenshot locally, paste remotely](media/overview-en.png)

1. **Remote PC:** install, choose Receiver, then copy the pairing code.
2. **Local PC:** install the same EXE, choose Sender, then paste the pairing code.
3. **Use it:** Win+Shift+S locally → wait for 100% → Ctrl+V remotely.

Windows 10/11 · MIT · Install on both PCs · Independent project, not affiliated with Google.

This is an **unsigned release candidate**. Windows may show an unknown-publisher warning. [Code signing policy](CODE-SIGNING.md)
