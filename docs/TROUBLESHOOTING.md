# 遇到問題

| 問題 | 怎麼做 |
| --- | --- |
| 遠端重開後不能傳 | 遠端按「配對電腦」重新複製配對碼；本機按「配對電腦」貼上新碼 |
| 配對碼貼不上 | 確認在手邊的工具輸入，不是在遠端畫面內；可用其他可信方式傳送文字 |
| 配對碼外洩 | 遠端配對視窗按「重設配對」，再讓自己的本機重新配對；舊密鑰失效 |
| 卡在連線或下載 | 兩台都要上網；接收端需能連 GitHub、Cloudflare。確認時鐘正確 |
| 已到 100% 但貼不上 | 選能貼圖片的輸入區；傳完後不要再複製別的文字 |
| 沒傳出舊截圖 | 工具啟動後再截一次；啟動前的圖片不會自動送出 |
| 按 X 後找不到 | 從 Windows 開始選單開啟工具，或雙擊通知區圖示 |
| Windows 擋住安裝 | 目前未簽章，不能保證免警告；請等簽章版或依組織規定處理 |
| 從 v0.1 升級 | 兩台都裝新版，重新配對；不匯入舊 EXE 內的密鑰 |

仍有問題：[回報錯誤](https://github.com/evan6007/chrome-remote-desktop-image-paste/issues)。附版本、角色與錯誤文字即可，**不要附配對碼、私人圖片或設定檔**。
