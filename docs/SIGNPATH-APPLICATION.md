**Tagline:** Paste local screenshots into a paired remote Windows computer while using Chrome Remote Desktop.

**Description:** Chrome Remote Desktop Image Paste is an independent open-source Windows utility that restores an image-paste workflow between two computers chosen by their operator. Users install the same application on both machines, select their roles, and exchange a private pairing code. Newly copied images are encrypted before transmission and placed into the receiver's native Windows clipboard, with progress and delivery confirmation. The application provides opt-in login startup, pause and quit controls, and per-user uninstallation. It is not affiliated with Google or Cloudflare.
